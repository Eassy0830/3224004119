# 小学四则运算题目生成器

零依赖 Node.js 18+ 命令行程序。所有运算使用 `BigInt` 实现的精确有理数，因此不会出现浮点误差。

## 运行

在项目根目录执行：

```powershell
node Myapp.js -n 10 -r 10
node Myapp.js -e Exercises.txt -a Answers.txt
node tests/test.js
```

生成模式会在当前目录写入 `Exercises.txt`、`Answers.txt`；判题模式写入 `Grade.txt`。

`-r` 是生成模式必填参数：自然数范围为 `[0, r)`，生成的真分数分母小于 `r`。`-n` 和 `-r` 均须为正整数。

## 实现约束

- 每题随机含 1 至 3 个运算符；每次构造减法均检查左值不小于右值。
- 除法仅保留结果大于 0 且小于 1 的运算。
- 每棵表达式树有规范键：只在每个 `+`、`×` 节点排序左右子树，既去掉交换律重复，也不错误使用结合律。
- 判题器按优先级和括号解析题目，支持 `×`/`*`、`÷`/`/` 和两种带分数撇号。

## 文件格式

```text
1. 1/6 + 1/8 =
2. 3 - 1 =
```

答案行格式为 `1. 7/24`。带分数写作 `2’3/8`。
